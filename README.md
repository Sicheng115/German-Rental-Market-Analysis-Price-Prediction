# German-Rental-Market-Analysis-Price-Prediction

## Overview

This project analyzes rental housing listings across Germany to identify the key drivers of rental prices and develop predictive models.

## Objectives

* Identify the main factors influencing rental prices
* Clean and validate complex rental housing data
* Explore regional and property-level rental patterns
* Build machine learning models to predict rental prices
* Generate actionable insights for data-driven pricing decisions
